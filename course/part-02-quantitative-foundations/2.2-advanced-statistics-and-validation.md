## 57. White's Reality Check, Hansen's SPA test, and data-snooping controls

**Method**
```
1. Test statistic: T = max over strategies k of  sqrt(n) * mean_k        (the best strategy)
2. Build the null: subtract each strategy's own mean so every true mean is zero.
3. Block-bootstrap the same time indices across all strategies, recompute the maximum, B times.
4. p-value = fraction of bootstrap maxima >= observed T.
```

**Worked example.** 50 strategies, each 500 days of pure noise (true mean 0, daily vol 1%).
- best strategy's t-statistic = **2.75**, naive p-value = **0.003** (looks like a discovery)
- the max of 50 pure-noise t-stats is expected near 2.05 anyway
- Reality Check p-value = **0.15**, correctly not significant

**Code:** `t57_reality_check`
**Watch out:** the test is only as honest as the list of strategies you give it. Include everything you tried.

## 58. Sharpe ratio under autocorrelation (Lo adjustment) and minimum track record length

**Formulas**
```
Lo annualization:  SR_annual = eta(q) * SR_period
eta(q) = q / sqrt( q + 2 * sum_{k=1..q-1} (q - k) * rho_k )        (q periods per year)
Minimum track record length (observations):
n* = 1 + [ 1 - skew*SR + (kurt-1)/4 * SR^2 ] * ( z_alpha / (SR - SR0) )^2
```

**Worked example, Lo.** Monthly Sharpe 0.20, autocorrelations rho_1 = 0.30, rho_2 = 0.10, rho_3 = 0.05, the rest zero.
- naive annual Sharpe = 0.20 x sqrt(12) = **0.693**
- eta(12) = 2.588, so Lo-adjusted annual Sharpe = **0.518** (about 25% lower)

Positive autocorrelation (typical of smoothed or illiquid returns) inflates the naive figure.

**Worked example, track record.** Annual Sharpe 1.0 (daily 0.063), skew -0.5, kurtosis 5, benchmark 0, 95% one-sided (z = 1.645):
n* = **707 days, about 2.8 years** before a Sharpe of 1 is statistically distinguishable from zero.

**Code:** `t58_lo_and_mintrl`

## 59. Ergodicity and why ensemble averages mislead single-account outcomes

**Formulas**
```
Each round: multiply wealth by 1.5 or 0.6, 50/50.
ensemble (expected) growth per round = 0.5 * 1.5 + 0.5 * 0.6 - 1 = +5.0%
time-average growth per round       = sqrt(1.5 * 0.6) - 1 = -5.13%
```

**Worked example.** 20,000 players, 100 rounds each.
- expected wealth multiple after 100 rounds = 1.05^100 = **131.5**
- but median wealth = (0.9)^50 = **0.0052**, i.e. a 99.5% loss
- **86.6%** of players end below where they started, **76%** end with less than 10% of their capital

The average is carried by a few astronomically lucky paths. A single account lives one path.

**Code:** `t59_ergodicity`
**Watch out:** this is why position sizing (Kelly, volatility targeting) maximizes the geometric growth rate, not the arithmetic expectation.

## 60. Causal inference (Granger causality, instrumental variables, double ML) vs. correlation

**Formula** (Granger F-test, p lags)
```
restricted:    y_t on its own p lags
unrestricted:  y_t on its own p lags and p lags of x
F = ((RSS_r - RSS_u) / p) / (RSS_u / (n - p - k_u))          k_u = parameters in the unrestricted model
```

**Worked example.** Data generated as y_t = 0.4 y_{t-1} + 0.3 x_{t-1} + noise, n = 600, p = 2. Critical F(2, ~590) at 5% is about 3.01.
- does x help predict y? F = **16.1** (reject: yes)
- does y help predict x? F = **2.2** (do not reject)

**Code:** `t60_granger`
**Watch out:** "Granger-causes" means predictive precedence. A third variable can drive both, and a common trend produces false positives unless you difference or detrend.

## 61. Quantile regression and non-parametric methods

**Formulas**
```
Pinball loss for quantile tau:  rho_tau(r) = r * (tau - 1[r < 0])
Quantile regression: minimize sum rho_tau( y_i - x_i'b )         (solved here by iterative reweighting)
```

**Worked example.** y = 0.3x + (0.5 + 0.5x) e with e standard normal, x uniform on (0, 2): the spread widens with x. Theory says the tau-quantile line has slope 0.3 + 0.5 z_tau.

| tau | Fitted slope | Theory |
|---|---|---|
| 0.05 | -0.537 | -0.522 |
| 0.50 | 0.263 | 0.300 |
| 0.95 | 1.161 | 1.122 |

Ordinary regression would only report the middle line (slope about 0.3). Quantile regression shows how the **tails** respond to the signal.

**Code:** `t61_quantile_regression`

## 62. Variance ratio test and Hurst exponent

**Formulas**
```
VR(q) = Var( q-period return ) / ( q * Var( 1-period return ) )
VR = 1 random walk;  VR > 1 trending (positive autocorrelation);  VR < 1 mean-reverting
Hurst H: 0.5 random walk, > 0.5 trending, < 0.5 mean-reverting
```

**Worked example.** 20,000 simulated daily returns.

| Process | VR(2) | VR(5) | VR(10) |
|---|---|---|---|
| Random walk | 1.004 | 1.020 | 1.023 |
| Trending (phi = +0.2) | 1.196 | 1.368 | 1.469 |
| Mean-reverting (phi = -0.2) | 0.804 | 0.726 | 0.682 |

**Code:** `t62_variance_ratio`
**Watch out:** use many observations. With a few hundred points the ratios scatter widely.

## 63. Ornstein-Uhlenbeck calibration and half-life of mean reversion

**Formulas**
```
dX = theta * (mu - X) dt + sigma dW
exact step:  X_{t+1} = mu + (X_t - mu) * e^(-theta) + noise
regression:  dX_t = a + b * X_{t-1} + e     then   theta = -ln(1 + b)
half-life = ln(2) / theta
```

**Worked example.** True theta = 0.10, so the true half-life = **6.93 periods**. Estimate from 400 independent samples of 500 points each:
- median estimated half-life = **6.36**
- middle 80% of estimates: **4.93 to 8.48**

A single estimate can be off by roughly 30%. Do not size a trade on a half-life estimated from a few hundred points without an uncertainty range.

**Code:** `t63_ou_half_life`

## 64. Filters and signal processing (low-pass, Hodrick-Prescott, Savitzky-Golay)

**Idea.** A two-sided (centered) filter at time t uses prices after t. A causal filter (EMA) uses only the past.
```
EMA:  y_t = a * x_t + (1 - a) * y_{t-1},   a = 2 / (w + 1)
```

**Worked example.** Pure random-walk prices (nothing is predictable). Correlation between each filter's slope at time t and the **next** return:
- centered 11-point moving average: **+0.304** (spuriously "predictive": the filter contains the future)
- EMA (window 11): **+0.002** (correctly zero)

A backtest using a centered filter, a Hodrick-Prescott trend, or a zigzag drawn with hindsight would show a strong edge that does not exist.

**Code:** `t64_filter_lookahead`

## 65. Effective sample size and overlapping-observation problems

**Formulas**
```
For L-day overlapping returns built from independent daily data, rho_k = (L - k)/L for k < L.
variance inflation = 1 + 2 * sum_{k=1..L-1} rho_k          effective n = n / inflation
```

**Worked example.** 1,000 overlapping 5-day returns of independent daily data. rho = 0.8, 0.6, 0.4, 0.2, so inflation = 1 + 2 x 2.0 = 5.
- effective sample size = 1000 / 5 = **200**
- simulation: the true standard error of the mean is **2.26** times the naive one (theory: sqrt(5) = 2.24)

A t-statistic computed naively from overlapping returns is inflated by more than a factor of two.

**Code:** `t65_effective_sample_size`
**Watch out:** the same applies to ML labels that look forward several days (see topics 360 and 361).
