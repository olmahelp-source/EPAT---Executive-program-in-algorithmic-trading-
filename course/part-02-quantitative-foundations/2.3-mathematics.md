## 66. Linear algebra (eigen decomposition, SVD, PCA)

**Formulas**
```
Covariance (or correlation) matrix  C = V * diag(lambda) * V'
eigenvectors V = principal components;  eigenvalue lambda_i = variance of component i
explained variance ratio = lambda_i / sum(lambda)
condition number = lambda_max / lambda_min
```

**Worked example.** Correlation matrix of three assets: rho_12 = 0.8, rho_13 = 0.6, rho_23 = 0.7.
- eigenvalues: **2.403, 0.414, 0.183** (they sum to 3, the trace)
- explained variance: **80.1%, 13.8%, 6.1%**
- first component loadings (0.58, 0.60, 0.55) all have the same sign: a common "market" factor
- reconstruction error of V diag(lambda) V' = 1e-15; condition number = 13.1

**Code:** `t66_pca`
**Watch out:** fit PCA on training data only. The sign of a component is arbitrary.

## 67. Covariance estimation (Ledoit-Wolf shrinkage, random matrix denoising)

**Formulas**
```
Shrinkage:  Sigma* = delta * m * I + (1 - delta) * S         m = trace(S)/N,  S = sample covariance
Marchenko-Pastur noise band for N variables, T observations, unit variance:
   lambda_max = (1 + sqrt(N/T))^2          eigenvalues below this are indistinguishable from noise
```

**Worked example.** N = 50 assets, T = 60 days (true covariance: one factor plus idiosyncratic noise). Build the minimum-variance portfolio from each estimate, then measure its true volatility (200 repetitions).

| Estimator | Condition number | Realized daily volatility |
|---|---|---|
| Sample covariance | 4,798 | **2.28%** |
| Ledoit-Wolf (shrinkage about 6%) | 177 | **1.20%** |
| Best possible (true covariance) | n/a | 0.91% |

Marchenko-Pastur upper edge for N/T = 50/60 is 3.66. A little shrinkage cuts realized risk nearly in half.

**Code:** `t67_covariance_shrinkage`
**Watch out:** the sample covariance of N assets from T < 2N observations is dangerously noisy for any optimizer.

## 68. Calculus and numerical differentiation

**Formulas**
```
forward difference:  f'(x) ~ (f(x+h) - f(x)) / h               error ~ O(h)
central difference:  f'(x) ~ (f(x+h) - f(x-h)) / (2h)          error ~ O(h^2)
rounding error ~ eps / h;  best central step h ~ eps^(1/3) ~ 6e-6
```

**Worked example.** f(x) = e^x at x = 1; exact derivative 2.718282.

| h | Forward error | Central error |
|---|---|---|
| 1e-1 | 1.4e-1 | 4.5e-3 |
| 1e-3 | 1.4e-3 | 4.5e-7 |
| 1e-5 | 1.4e-5 | **5.9e-11** |
| 1e-8 | 6.6e-9 | 6.6e-9 |
| 1e-10 | 1.5e-6 | 6.7e-7 |
| 1e-12 | 4.3e-4 | 2.1e-4 |

Shrinking h helps until rounding error takes over. The best central-difference step is near 1e-5, not 1e-12.

**Code:** `t68_numerical_derivative`
**Watch out:** this is how to sanity check option Greeks (topic 400).

## 69. Convex and non-convex optimization

**Formulas** (minimum variance, fully invested)
```
minimize w' S w  subject to  1'w = 1      closed form:  w = S^-1 1 / (1' S^-1 1)
Long-only: no closed form. Active-set method: if any weight is negative, remove the asset with the most negative weight, re-solve.
```

**Worked example.** Three assets with volatilities 15%, 30%, 10% and correlations rho_12 = 0.95, rho_13 = 0.2, rho_23 = 0.1.

| Solution | Weights | Volatility |
|---|---|---|
| Unconstrained | (1.083, **-0.464**, 0.381) | 7.53% |
| Long-only (active set) | (0.264, 0, 0.736) | 9.03% |

The constraint costs 1.5 points of volatility, and it removes a leveraged short in the highly correlated asset.

**Code:** `t69_optimization` (`long_only_min_var`)

## 70. Stochastic calculus (Brownian motion, Ito's lemma)

**Formulas**
```
dS = mu S dt + sigma S dW
Ito:  d ln S = (mu - sigma^2 / 2) dt + sigma dW
S_T = S_0 * exp( (mu - sigma^2/2) T + sigma sqrt(T) Z ),  Z ~ N(0,1)
E[S_T / S_0] = e^(mu T)          median[S_T / S_0] = e^((mu - sigma^2/2) T)
```

**Worked example.** mu = 10%, sigma = 30%, T = 1 year (1,000,000 simulated paths).
- expected log return: theory **5.50%**, simulation 5.48%
- expected gross return: theory **1.1052**, simulation 1.1051
- median gross return: theory **1.0565**, simulation 1.0563

The typical (median) outcome earns about 5.65%, while the mean earns 10.52%. The gap (about 4.9 points) comes from volatility drag: in log terms the drift is lower by sigma^2 / 2 = 4.5%.

**Code:** `t70_ito`

## 71. Stochastic differential equations and simulation

**Formulas** (Euler-Maruyama scheme for the OU process)
```
X_{t+dt} = X_t + theta (mu - X_t) dt + sigma sqrt(dt) Z
exact:  E[X_T] = mu + (x0 - mu) e^(-theta T)          Var[X_T] = sigma^2 / (2 theta) * (1 - e^(-2 theta T))
```

**Worked example.** theta = 0.5, mu = 0, sigma = 1, x0 = 2, T = 5 (200,000 paths). Exact mean 0.1642, exact variance 0.9933.

| Step dt | Simulated mean | Simulated variance |
|---|---|---|
| 1.0 | 0.0609 | 1.3318 |
| 0.1 | 0.1566 | 1.0234 |
| 0.01 | 0.1610 | 0.9930 |

Discretization bias shrinks with the step size, and it can be large when dt is not small.

**Code:** `t71_sde_simulation`

## 72. Numerical methods (finite differences, trees, Monte Carlo, quasi-Monte Carlo)

**Formulas**
```
Monte Carlo estimate = average of discounted payoffs;  standard error = sample std / sqrt(N)
Antithetic variates: pair each draw Z with -Z, average the two payoffs
Black-Scholes call = S N(d1) - K e^(-rT) N(d2),  d1 = [ln(S/K) + (r + sigma^2/2) T] / (sigma sqrt T),  d2 = d1 - sigma sqrt T
```

**Worked example.** European call, S = 100, K = 105, T = 1, r = 5%, sigma = 20%. Black-Scholes price = **8.0214**.

| Method (100,000 paths) | Estimate | Standard error |
|---|---|---|
| Plain Monte Carlo | 7.984 | 0.0417 |
| Antithetic | 8.037 | **0.0234** |

Antithetic sampling cut the standard error by about 44% at no extra random draws.

**Code:** `t72_monte_carlo_option` (`bs_call` in `common.py`)

## 73. Information theory (entropy, mutual information)

**Formulas**
```
Entropy:               H(Y) = - sum p(y) ln p(y)
Mutual information:    I(X;Y) = sum p(x,y) * ln( p(x,y) / (p(x) p(y)) )         0 if independent
```

**Worked example.** 5,000 observations. Feature x is binned into 5 quantile groups. y = next-day direction, with P(up) = 0.5 + 0.05 tanh(x), a weak non-linear link.
- H(Y) = 0.693 nats (a fair coin)
- I(X;Y) = **0.00244** nats
- 95th percentile of 500 shuffled-y values: 0.00091; permutation p-value **< 0.002**

The dependence is tiny but statistically visible, and a linear correlation test could miss the non-linear part of it.

**Code:** `t73_mutual_information`

## 74. Fourier and wavelet analysis, spectral methods

**Formulas**
```
Periodogram:  P(k) = |FFT(x - mean)|^2 / n        frequency k  corresponds to period n / k
```

**Worked example.** x_t = sin(2 pi t / 20) + noise with sd 2, n = 512 points. The strongest frequency index is k = 26, giving period 512 / 26 = **19.7** (true period 20). Peak power 119, while the 95th percentile of the largest peak in pure noise is 34, so the cycle is real.

**Code:** `t74_fourier`
**Watch out:** always compare against surrogate noise, otherwise you will "find" cycles in random data.

## 75. Game theory

**Formulas** (2x2 game, interior mixed equilibrium)
```
Row payoffs A = [[a, b], [c, d]], column payoffs B = [[e, f], [g, h]]
column plays column-1 with probability q = (d - b) / (a - b - c + d)   (makes the row player indifferent)
row plays row-1 with probability     p = (h - g) / (e - g - f + h)    (makes the column player indifferent)
```

**Worked example.** Market maker (rows: Tight, Wide) against an informed trader (columns: Trade, Skip). Market maker payoffs: [[-3, 2], [1, 0]]. Informed payoffs: [[3, 0], [-1, 0]].
- market maker quotes Tight with probability **p = 0.25**
- informed trader trades with probability **q = 1/3**
- expected payoff: market maker 0.333 either way (indifferent), informed trader 0 either way

Even in equilibrium the market maker widens the spread 75% of the time to protect against being picked off.

**Code:** `t75_game_theory` (`mixed_nash_2x2`)

## 76. Optimal control and dynamic programming

**Formulas** (liquidate Q shares over T periods)
```
cost per period = q_t^2 (temporary impact) + lambda * (x_t - q_t)^2 (risk on shares still held)
Bellman:  V_t(x) = min over q in [0, x] of  q^2 + lambda (x - q)^2 + V_{t+1}(x - q)
last period: must sell everything left:  V_T(x) = x^2
```

**Worked example.** Q = 10 shares, T = 5 periods.

| Risk weight lambda | Optimal schedule | Total cost |
|---|---|---|
| 0 (impact only) | 2, 2, 2, 2, 2 (equal split, TWAP) | 20 |
| 0.5 | 5, 3, 1, 1, 0 | 51 |
| 2.0 | 7, 2, 1, 0, 0 | 74 |

The more you dislike holding risk, the more front-loaded the optimal schedule. This is the Almgren-Chriss intuition in discrete form.

**Code:** `t76_dynamic_programming` (`optimal_liquidation`)

## 77. Graph theory and network analysis of correlations

**Formulas**
```
distance d(i,j) = sqrt( 0.5 * (1 - rho_ij) )        rho = 1 -> 0,  rho = 0 -> 0.707,  rho = -1 -> 1
Minimum spanning tree (Kruskal): sort edges by distance, add an edge if it does not form a cycle.
```

**Worked example.** Five assets, two natural groups (A, B, C) and (D, E). The tree has 4 edges:
- A-B (0.316), D-E (0.354), A-C (0.387), and a single bridge B-D (0.592)

The tree shows the two clusters and the one link connecting them.

**Code:** `t77_graph_mst` (`minimum_spanning_tree`)

## 78. Fractional differentiation and memory-preserving stationarity

**Formulas**
```
Weights:  w_0 = 1,   w_k = - w_{k-1} * (d - k + 1) / k
Fractionally differenced series:  X~_t = sum_k w_k X_{t-k}       (truncate when |w_k| < threshold)
d = 0: original series;  d = 1: ordinary first difference;  0 < d < 1: partial
```
For d = 0.4 the first weights are 1, -0.4, -0.12, -0.064, -0.0416.

**Worked example.** Log prices of a random walk with drift, 4,000 points (ADF 5% critical value -2.86):

| d | ADF statistic | Stationary at 5%? | Correlation with original series |
|---|---|---|---|
| 0 | -2.36 | no | 1.000 |
| 0.05 | -2.77 | no | 1.000 |
| **0.10** | **-3.49** | **yes** | **0.997** |
| 0.2 | -5.79 | yes | 0.979 |
| 0.4 | -14.35 | yes | 0.871 |
| 0.6 | -29.33 | yes | 0.639 |
| 1.0 | -63.15 | yes | 0.031 |

The smallest d that passes is about 0.1, which keeps 99.7% correlation with the level series. Ordinary differencing (d = 1) keeps only 3% of the information.

**Code:** `t78_fractional_differentiation` (`ffd_weights`, `frac_diff`)
